A high-performance Progressive Web Application (PWA) built for educational institutions, educators, and administrators to track student attendance in real-time, generate automated analytics, and export roster reports.

---

## 🔗 Live Application
🌐 **Production URL**: [https://attendify-student-system.vercel.app](https://attendify-student-system.vercel.app)

---

## ⚡ Key Highlights

- **⚡ Fast Attendance Tracking**: Single-tap toggle for Present, Absent, and Late statuses with keyboard shortcuts.
- **📊 Real-Time Analytics**: Live attendance percentage rates, risk alerts for students below threshold limits.
- **📁 CSV Data Pipeline**: Instant import and export of student rosters via PapaParse with validation checks.
- **📴 Offline-First PWA**: Powered by `vite-plugin-pwa` for seamless field usage even without network connectivity.
- **🎨 Modern Glassmorphic UI**: Built with Tailwind CSS v4, Lucide icons, and fluid animations.
- **🗄️ Supabase Cloud Ready**: Structured schema bindings for cloud sync and multi-classroom access.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, React Router v7
- **Styling**: Tailwind CSS v4, `clsx`, `tailwind-merge`
- **Data & Parsing**: `papaparse` (CSV engine), `date-fns`
- **Database Backend**: `@supabase/supabase-js`
- **Build & PWA**: Vite 8, `vite-plugin-pwa`

---

## 🚀 Local Development Setup

```bash
# 1. Clone repository
git clone https://github.com/Tamanash-009/student-attendance-system-app.git
cd student-attendance-system-app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
